THREE-MODALITY GA FUSION FOR TRANSE
================================

Agreed design
-------------
Train once, freeze the checkpoint, evolve relative contributions.
Use separate visual, textual, and structural TransE scores without ANN heads.
Fixed modality order: visual, textual, structural.
Individual: [w_visual, w_textual, w_structural].
Every weight is finite/nonnegative and the sum is one (two degrees of freedom).
Fitness: maximize filtered validation MRR for head and tail prediction.
Accepted/rejected decisions are incidental and do not enter the fitness.

Training stage
--------------
Reuse vlkge/configs/wn9_img/transe_clip.yaml. Create no new config file.
CLI overrides select MASGATransE and enable all three modalities.
Start with equal thirds; learn structural entity embeddings and shared
relations using the existing negative sampling, logistic loss, and Adagrad.
Keep supplied visual/textual feature tables frozen.
Save the effective CLI-overridden settings and mappings in the checkpoint.
A fresh three-modality checkpoint is required; preserve the old experiment.
Defer final test evaluation with --skip_final_test.

GA stage
--------
Freeze every model parameter, including structural entities and relations.
Cache three scores per replacement candidate.
Population 30: equal thirds + three single-modality vertices + 26 random vectors.
Initialization: uniform weight triangle, Dirichlet(1,1,1).
Selection: tournament size 3.
Crossover: arithmetic, one shared coefficient for the entire vector.
Crossover probability: 0.8 per parent pair.
Optional bounded SBX: eta 20, followed by sum-to-one repair.
Mutation: reset the complete vector uniformly over the valid triangle.
Mutation probability: 0.2 per offspring.
Elites: 2 unchanged individuals.
Maximum generations: 30 after evaluating the initial population.
Default patience: 10; --patience 0 disables early stopping.
Seed: 42; repeat with other seeds and separate output paths as needed.
Crossover and mutation are independent stages.
Memoize immutable weight-vector tuples; report requests and unique evaluations.
These are starting settings, not tuned optima or guaranteed global optima.

Evaluation and comparisons
--------------------------
All entities are replacement candidates; use both head and tail queries.
Separate head/tail filters, retaining each query's target.
GA/agent validation filters: training + full validation positives.
Final test filters: training + validation + test positives.
Stable ties: score descending, entity ID ascending.
The existing training helper retains its earlier all-known filtering; use
fresh equal-thirds metrics for comparisons, not older training/ANN log numbers.
Report overall and per-relation MRR and Hits@1/3/10.
Baselines: equal thirds and visual-only/textual-only/structural-only.
Random-search budget matches GA unique evaluations and includes all references.
Grid-search budget is a cap on a complete triangular lattice; report actual
count. A 0.05 lattice has 231 candidates. Test metrics do not select weights.

Agents and reporting
--------------------
VisualAgent, TextualAgent, StructuralAgent, then DecisorAgent.
Four messages per observed triple. Keep structural scores in CSV/JSONL.
Adapter and model use one shared three-score fusion method.
Preserve decision threshold 0.5 for the ANN-style decision test, outside MRR.
Version 2 files record modality_order, all named weights, and checkpoint hash.
Reject old two-modality checkpoint/weights in structural inference.
Continue displaying archived two-modality summary files without changing them.
Show equal-thirds and best-vector metrics in ANN-style reports.

Commands
--------
See vlkge/ga/README.md for background/nohup and all validation/test commands.

Train (create the output directory before redirecting a background log):
python -m vlkge.scripts.train --config vlkge/configs/wn9_img/transe_clip.yaml --model MASGATransE --fusion_mode average --use_structural --use_visual --use_textual --seed 42 --skip_final_test --save_path runs/wn9_img/mas_gatranse_3modalities/mas_gatranse_average_3modalities_seed42.pt

Evolve:
python -m vlkge.ga.run_fusion_ga --config vlkge/configs/wn9_img/transe_clip.yaml --checkpoint runs/wn9_img/mas_gatranse_3modalities/mas_gatranse_average_3modalities_seed42.pt --output-dir runs/wn9_img/mas_gatranse_3modalities/ga_seed42

Agents on validation:
python -m vlkge.mas.evaluate_ga_mas --config vlkge/configs/wn9_img/transe_clip.yaml --checkpoint runs/wn9_img/mas_gatranse_3modalities/mas_gatranse_average_3modalities_seed42.pt --fusion-weights runs/wn9_img/mas_gatranse_3modalities/ga_seed42/fusion_weights.json --split val --output-dir runs/wn9_img/mas_gatranse_3modalities/agents_validation

Boundaries
----------
The selected weights express relative score contribution for this trained
checkpoint. They are not probabilities or intrinsic modality importance.
A fresh checkpoint for each individual is intentionally outside this design.
No new or changed YAML configuration is required.
